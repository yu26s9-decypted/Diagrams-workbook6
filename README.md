# Diagrams — Workbook 6

A collection of database and system design diagrams created during my studies at **LTCA (Liftoff Tech Career Accelerator)**.

## About This Project

This workbook contains visual diagrams (built with **draw.io**) that model the structure of databases and systems. Diagram work is an essential part of software engineering — before writing code, you need to design the data model.

## What I Learned

- How to read and create **Entity Relationship Diagrams (ERDs)** to model database schemas
- Identifying entities, attributes, and the relationships between them (one-to-one, one-to-many, many-to-many)
- Using **draw.io** as a diagramming tool
- Translating a real-world problem into a structured data model
- The importance of planning database structure before writing SQL or code
